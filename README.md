# Job-Specific-AI-Agents
Using Copilot Studio to Create Job Specific AI Agents

This repo is a central location for sharing out the slides and Agent for the discussion "Using Copilot Studio to Create Job Specific AI Agents".

PRE-REQUISITE:
1. A Dataverse table of "Approved Devices" containing the branded name of the device, device inventory count, and any other hardware information relevent.
2. A Dataverse table for "Device Procurement" contaning the ProcurementID, assigned user, Date, and any other relevent fields for your Organization, i.e. inventory tag, ect.
3. The Following M365 Licensing: E1 or higher license, Power Automate free license, Copilot license, Copilot Studio License.
